OPTIONAL GAMEBANANA MOD SYNC - REVIEW SUMMARY
2 November 2026 | Draft PR #152

This adds an optional Windows launcher integration for sharing exact GameBanana
mod uploads with lobby members. It preserves OCTR's missing-character-to-Crash
fallback. Downloads are staged and explicitly imported disabled; downloading a
package is never reported as proof that the running game loaded it.

Implemented
- Opt-in launcher toggle, background worker and retained Nitro-style status bar.
  Drawing is independent of input focus; this does not create a desktop overlay.
- Canonical gamebananapageurl.txt discovery, exact upload resolution, bounded
  HTTPS downloads, package checks and receipts. No GitHub mod download catalogue.
- US/EU upload selection using explicit title IDs and matching release versions.
  Executable patch targets are checked against the actual local game. Alternate
  regional uploads get their own hashes; mixed-edition readiness is not assumed.
- Closed-game receipt import from the launcher, followed by manual enable,
  restart and rejoin. Safe hot loading is not implemented.
- Standalone Go bridge for current-server authentication/membership adapters,
  a fixed maximum 20-second hold, heartbeat expiry and an admin kill switch.
  Disabled, failed, unavailable or late participants continue with normal fallback.
- Duplicate JSON fields/member IDs rejected; expired room capacity is recovered.
- English/Spanish quick starts, server wiring notes, protocol documentation,
  a local HTTPS demo and a source-overlay/patch packager.

Verified locally and/or in CI
- 40 focused Python tests and 8 existing runner tests.
- 16 Go tests with the race detector; go vet.
- Real Python client to Go server over loopback HTTPS. Includes signatures,
  replay rejection, deadline, disconnect, opt-out, admin disable and regional
  hash mismatch fallback. Synthetic local accounts only; no production service.
- Two headless C++/ImGui tests, including identical panel geometry across focus
  loss/regain. Actual game focus/fullscreen acceptance still needs a live test.
- Windows launcher source compiles/links with C++20, Win32 and D3D11. This is a
  resource-less check executable, not the production GPU/distribution build.
- Patch applies to clean upstream base 3885d1aea24d19ed9b31f96fba57a5cce92183cd;
  every changed file and ZIP entry is byte/hash verified during packaging.

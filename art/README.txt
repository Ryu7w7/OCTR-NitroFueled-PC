CTR Nitro-Fueled PC launcher UI artwork

launcher/io.github.sacredfire.Launcher.png: user-supplied rounded artwork, fitted to 208px
inside a transparent 256px canvas so its visual size matches other desktop icons.
Shared by the launcher, game and tray. packaging/windows/icons/ctr.ico contains the same
artwork at 16, 24, 32, 48, 64, 128 and 256 pixels.
Regenerate both from the original upload with scripts/build_launcher_icons.py (Pillow required).
